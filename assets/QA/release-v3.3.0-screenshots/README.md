# DILIGENT v3.3.0 release screenshot candidates

Approval status: approved by the user for v3.3.0 release documentation.

These candidates were captured from the running source-mode application with
synthetic or public catalog data only. The standard capture profile is a
1440 x 1000 browser window in the light theme; the saved PNGs use the
1431 x 994 effective content frame where that frame is appropriate. The
timeline overview uses an extended 1430 x 1124 documentation frame so its
page heading, review controls, chronology, and one complete event are visible
together without truncating the event card. No browser or development-tool
chrome is included.

| `01-dili-agent-synthetic-input.png` | DILI Agent with a structured fictional case ready for review | README, Run a DILI assessment |
| `02-clinical-sessions-synthetic-report.png` | Clinical Sessions with a saved synthetic report, detected drugs, and hepatotoxicity summary | README, Review the result / Work with saved sessions |
| `03-patient-timeline-overview.png` | Saved Patient Timeline overview with review controls, chronology, and a complete baseline event | README, Use the timeline |
| `04-patient-timeline-event-inspector.png` | Timeline chronology with a selected laboratory event and supporting detail inspector | User timeline documentation |
| `05-data-inspection-drug-catalog.png` | Data Inspection filtered to public amoxicillin catalog records | README, Data Inspection |
